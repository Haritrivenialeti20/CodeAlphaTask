# 🌐 CodeAlpha Language Translation Tool

A web-based language translation tool developed as part of the CodeAlpha Artificial Intelligence Internship.

## 🚀 Features

- Translate text between multiple languages
- Select source and target languages
- Swap source and target languages
- Copy translated text
- Clear input and translation
- Responsive and user-friendly interface
- Backend API built with Node.js and Express
- Translation powered by Google Translate-compatible endpoint

## 🛠️ Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js
- CORS
- Fetch API

### Translation API
- Google Translate-compatible translation endpoint
